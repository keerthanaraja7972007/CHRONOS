# Judge demo guide

## Three-minute flow

1. Open the landing page and select **Try demo mode**.
2. Choose **Refactor payment queue and retry policy** (critical risk).
3. Start the agent swarm. Highlight the live DebateLog, historical grounding, risk score, and merge-block verdict.
4. Show the generated pre-mortem and rollback runbook.
5. Open Settings and reset the demo to prove the system is self-contained and repeatable.

## Talking points

- CHRONOS analyzes structural repository context before any reasoning.
- Specialized agents are parallel, typed, and independently extensible.
- The risk verdict is transparent: evidence, confidence, blast radius, and historical incidents are retained.
- Demo Mode requires no GitHub login, model API key, or external database service.

## Fallback

If a browser session is stale, reset Demo Mode and choose the critical PR again. The deterministic swarm produces the same grounded verdict.
